# Weather Forecast Web Application 🌤️

A dynamic and feature-rich web application developed as a Database Lab project. It enables users to check real-time weather forecasts, manage user authentication, and securely store forecast history using modern web technologies and a relational database.

---

## 🚀 Key Features
- **User Authentication:** Secure registration, login, and session management modules (`login.php`, `signup.php`, `logout.php`)[cite: 2].
- **Interactive Dashboard:** Dynamic weather data fetching using JavaScript and AJAX integrated with external Weather APIs for seamless user experience[cite: 2].
- **Forecast Management:** Allows users to save and view their searched weather conditions (`save_forecast.php`).
- **Admin & User Controls:** Dedicated functionality to manage user accounts and system overview (`manageusers.php`).

---

## 🛠️ Tech Stack
- **Backend:** PHP
- **Frontend:** HTML, CSS, JavaScript, AJAX[cite: 2]
- **Database:** MySQL (`weather_app.sql`)
- **Server:** Local Apache Server (XAMPP/WAMP)
